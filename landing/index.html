Carbon SuperAgent

Agentes autônomos que pegam uma tarefa do Linear, GitHub, Jira, ou de uma menção no Slack e no Telegram, e entregam um PR revisável, rodando no seu computador, com o Claude Code ou o Codex do seu plano. Você só é chamado quando precisa decidir, e decide com um clique.

Começar em 2 minutos → Ver código no GitHub
$ git clone https://github.com/leolegends/carbon-superagent && cd carbon-superagent && npm install && npm run setup

como funciona

Um ticket entra. Oito estágios depois, sai um PR.

Cada tarefa roda num git worktree isolado. O agente reporta progresso por um protocolo simples, e o painel mostra tudo em tempo real: plano, comandos, testes e pedidos de permissão.

    integrações

    Peça no chat. Responda com um clique.

    Mencione o bot no Slack ou no Telegram, ou ponha uma label numa issue do Jira: a tarefa entra na fila. Quando o agente precisa decidir, a pergunta chega com opções. Você clica, e ele continua de onde parou, no mesmo worktree.

    • JIRA CLOUD

      Label ou /carbon

      Issue com a label carbon ou um comentário /carbon … vira tarefa. O Carbon comenta o andamento, faz as perguntas e move o status até “Em revisão”.

    • SLACK

      @carbon no canal

      Atualizações na thread da menção e perguntas com um botão por opção, com a recomendada em destaque.

    • TELEGRAM

      /carbon no seu chat

      Só o chat autorizado cria tarefas e responde. As perguntas chegam com botões, direto no celular.

    • LINEAR E GITHUB

      Importe issues

      Importe na nova tarefa; o link do PR volta comentado no Linear.

    Webhooks por túnel HTTPS, aceitos só com a assinatura de cada serviço. Tokens ficam no banco local e nunca voltam ao navegador.

    harness

    28 skills de engenharia, instaladas em cada tarefa.

    O agente não depende de boa vontade: em cada etapa ele segue skills que transformam boas práticas em passos verificáveis. Teste falhando antes do fix, revisão com severidade, segurança, LGPD, migrações reversíveis, verificação antes de entregar. Adaptadas do Everything Claude Code para o protocolo do Carbon.

    eficácia

    Quanto o agente está ajudando, medido.

    O Mission Control mostra se vale a pena: quantas tarefas terminam bem, quantas viram PR, quantas rodam sem precisar de você, plano cumprido, testes verdes, achados críticos resolvidos, tempo e custo médios. Tudo calculado do que o Carbon registra, com as fórmulas à vista. Sem dado, aparece “sem dados”, nunca um palpite.

    inspiração e créditos

    De onde veio a ideia.

    DEEPSEEK-AI / DSH-SUPERAGENT-PROTOTYPE
    Menos atenção humana, mais valor entregue.

    O Carbon nasceu da filosofia do dsh-superagent-prototype, da DeepSeek: um agente que leva uma tarefa de ponta a ponta, com etapas explícitas, memória e reflexão, e que chama o humano só quando há decisão a tomar. Aqui essa ideia virou uma plataforma web local, ligada ao seu Linear, ao seu GitHub e aos agentes de código que você já usa.

    • Claude Code e Codex CLIOs executores. O Carbon orquestra; eles escrevem o código. Basta ter um dos dois.
    • Everything Claude CodeBase das 28 skills nativas do harness: TDD, verificação, revisão, segurança e mais, adaptadas ao protocolo do Carbon.
    • ascii-revealAs animações de decodificação em caracteres do painel (MIT).
    • GeistTipografia sans e mono.
    • E o nome: carbono, o elemento que se liga a quase tudo. Como um agente que se conecta ao seu fluxo.

    execução distribuída

    Escale para outras máquinas e para a AWS.

    Por padrão, uma tarefa por vez no seu computador. Com workers, várias tarefas rodam ao mesmo tempo em outros servidores, e o painel continua sendo o centro: fila, log ao vivo, perguntas, permissões e entrega aparecem nele como numa tarefa local. Para colocar um servidor novo, é um comando, como no Docker Swarm.

    LOCAL

    Esta máquina

    O padrão. Fila serial, sem rede, nada muda para quem já usa.

    POOL

    Cluster de workers

    Gere um token de join no painel e rode carbon join (ou um docker run) em cada servidor. Ele entra sozinho, recebe credencial própria e começa a pegar tarefas. Pause, retome ou remova servidores pelo painel.

    AGENTCORE · EXPERIMENTAL

    AWS AgentCore

    Uma sessão do Bedrock AgentCore Runtime por tarefa, na sua conta. Kit de deploy pronto. Experimental.

    # no painel: expõe só /api/worker/* (UI segue em 127.0.0.1) e gera o token de join
$ CARBON_WORKER_LISTEN=127.0.0.1:3418 npm start
$ carbon join-token --rotate

# em cada servidor novo (o comando já sai pronto em Configurações → Máquinas)
$ carbon join https://painel.exemplo.com --token cjt_…
entrou no cluster como "srv-1" · conectado ao painel · 1 slot(s) · claude

    começar

    Dois minutos, um terminal.

    O setup interativo checa o ambiente, detecta o agente instalado, cria seu perfil e já indexa o repositório. Depois é só abrir o navegador.

    # 1. clone e instale
$ git clone https://github.com/leolegends/carbon-superagent
$ cd carbon-superagent && npm install

# 2. setup interativo (ou pelo navegador em /setup)
$ npm run setup

# 3. sobe em http://127.0.0.1:3417
$ npm start
