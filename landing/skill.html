skill para claude code · experimental

Sua sessão do Claude Code chama reforço.

A skill carbon-coop pareia um servidor seu como servidor Orca e manda partes do trabalho para lá. Os workers usam o Claude Code deste computador, nenhuma porta fica aberta na internet e o resultado volta como branch para você revisar.

01 · O PROBLEMA

Sua máquina no limite, o servidor parado.

Várias tarefas abertas, build e testes disputando CPU. Você tem um servidor com folga, mas o código e o login do Claude Code estão aqui.

02 · CONECTAR

Uma conexão SSH, dois sentidos.

A skill checa tudo e liga um proxy local que lê o seu login do Claude Code no Keychain. Depois abre uma única conexão SSH: -L leva até o Orca do servidor e -R devolve o caminho até o proxy. Nenhuma porta pública.

› /carbon-coop connect carbon@servidor
✓ preflight: orca · ssh por chave · node 22
✓ proxy em 127.0.0.1:8787 (login fica aqui)
✓ túnel aberto
03 · PAREAR

O servidor vira um servidor Orca.

No servidor sobe orca-ide serve escutando só em 127.0.0.1. O link de pareamento vai direto para orca environment add: nunca é impresso e é apagado do log do servidor.

✓ orca-ide serve em 127.0.0.1:16768
✓ pareado como coop-servidor
04 · MANDAR

Só o commitado viaja.

Você pede em linguagem natural. A skill envia o commit atual por git/SSH para um repositório no servidor e inicia um worker lá com uma spec clara. Mudanças não commitadas ficam aqui; repositórios em blockedRepos nunca saem.

› manda os testes do módulo de auth pro servidor
✓ enviado a1f3c9e → coop/base-auth-tests
✓ worker iniciado em coop-servidor
05 · TRABALHAR

O worker usa o seu login, sem levá-lo.

O Claude Code do servidor manda um token falso para 127.0.0.1:8787; o túnel entrega no proxy daqui, que troca pelo login real. Se o worker tiver dúvida, a pergunta chega na sua sessão, e o que for decisão sua ele pergunta a você.

06 · TRAZER

O resultado volta como branch.

Quando o worker termina, a skill busca o branch coop/<slug> e mostra commits e diff. Revisar, mesclar aqui ou descartar é decisão sua; a skill não faz push.

✓ worker terminou · 3 commits
✓ coop-servidor/coop/auth-tests pronto para revisar
07 · DESLIGAR

Desligou, acabou o acesso.

/carbon-coop disconnect para o servidor Orca, fecha o túnel e o proxy. Sem túnel, o servidor não alcança mais a sua conta, e a credencial nunca esteve lá.

segurança

O que fica aqui, e o que você precisa saber.

O login fica aquiO worker manda um token falso; o proxy deste Mac injeta o real e só fala com api.anthropic.com.
Nenhuma porta públicaUma conexão SSH aberta daqui. No servidor, Orca e proxy escutam só em 127.0.0.1.
Só o commitado viajaRepositórios sensíveis entram em blockedRepos e não saem da máquina.
Root no servidorEnquanto o túnel estiver aberto, consegue usar a sua conta (sem levar a credencial) e lê o código enviado. Use servidores que você controla.
Mesma conta, mesma quotaMais máquinas trazem paralelismo e CPU, não mais limite de uso do plano.
Worker sem pedir permissãoO Orca abre o worker em modo sem permissões. O limite é a conta sem sudo e fora do docker, e a spec que proíbe mexer em infraestrutura.
